# My NixOS config

This repo contains the NixOS config for my Framework 13 AI 300 laptop.

Apply changes from this directory with `sudo nixos-rebuild switch --flake .#nixos`.
Then press **Super + Shift + C** to reload Sway.

**Super + D** opens a searchable menu with application
icons and descriptions. Try searches like `browser`, `file manager`, `editor`,
or `office`; use the arrow keys and Enter, or click an application to open it.
Press Escape to close the menu. **Super + E** opens the file manager directly.
